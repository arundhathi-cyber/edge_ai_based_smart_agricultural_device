# edge_ai_based_smart_agricultural_device
An Edge AI-based smart agriculture system using ESP32, Raspberry Pi 4B, and LoRa communication for real-time soil and environmental monitoring and intelligent crop recommendation. The ESP32 transmitter collects sensor data, including soil moisture, pH, NPK, temperature, and humidity, and transmits it over LoRa to a Raspberry Pi 4B receiver. A machine learning model processes the sensor readings locally to recommend suitable crops, while a touchscreen GUI displays real-time sensor values and predictions. The system is designed for offline operation in rural agricultural environments with limited internet connectivity. The project also explores ESP32-CAM integration for leaf health and animal detection, along with semantic communication to transmit meaningful information instead of raw images.
